# Iris Flower Classification

## Objective
The objective of this project is to classify Iris flowers into three species: Setosa, Versicolor, and Virginica using a Decision Tree Classifier.

## Steps Performed
1. Loaded the Iris dataset.
2. Checked the dataset structure and missing values.
3. Separated the features and target variable.
4. Split the dataset into training and testing data.
5. Built and trained a Decision Tree Classifier.
6. Predicted the flower classes using the test data.
7. Evaluated the model using accuracy, confusion matrix, and classification report.
8. Analyzed feature importance.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Outcome
The Decision Tree Classifier achieved an accuracy of 93.33%. Petal length was the most important feature for classification, followed by petal width.
